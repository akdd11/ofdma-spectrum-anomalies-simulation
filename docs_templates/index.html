Head

The framework generates labeled spectrograms of an OFDMA system with legitimate transmitters and jammers, based on ray-traced channels. These pages document the code in the src folder of the latest version on the main branch.

Pipeline

The scene generation with Blender (blender-python) is described in the README. The following scripts are run in this order:

  1. dataset_generation: ray tracing and generation of the custom intermediate data.
  2. custom_data_export: export to spectrogram and resource allocation images (or HDF5), labels and data splits.
  3. plot_figures: figures of the paper, from an exported dataset.

The shared functionality (OFDM signal generation, ray tracing, hardware impairments, data loading and datatypes) is in the utils package.
